Данный проект представляет собой комплексный анализ динамики цен на автомобильный бензин в регионах Южного федерального округа (ЮФО) за период с 2014 по 2025 год.

В рамках работы были проведены:

1. **Очистка и предобработка данных** — подготовка данных к анализу
2. **Исследовательский анализ (EDA)** — изучение структуры и закономерностей
3. **Анализ региональных различий** — выявление дисбаланса цен
4. **Анализ динамики по годам** — выявление трендов и сезонности
5. **Корреляционный анализ** — изучение связи между марками топлива
6. **Расчёт CAGR** — среднегодовой темп роста цен по регионам

**Цель исследования:** выявить ключевые закономерности в ценообразовании на топливо, определить региональные дисбалансы и разработать практические рекомендации.

## Данные

**Источник:** Росстат / Открытые данные

**Описание данных:**
- **Период:** 2014–2025
- **Регионы:** 8 субъектов ЮФО
- **Марки топлива:** АИ-92, АИ-95, АИ-98, Бензин автомобильный (средняя)

**Структура данных:**

| Колонка | Описание | Тип |
|---------|----------|-----|
| `Дата` | Дата наблюдения | datetime |
| `Область` | Регион ЮФО | object |
| `Бензин_автомобильный` | Средняя цена | float |
| `АИ-92` | Цена АИ-92 | float |
| `АИ-95` | Цена АИ-95 | float |
| `АИ-98` | Цена АИ-98 | float |
