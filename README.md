Данный проект представляет собой полный цикл анализа данных о ценах на автомобильный бензин в регионах Южного федерального округа (ЮФО) за период с 2014 по 2025 год.

**Цель исследования:** выявить ключевые тренды, региональные дисбалансы и построить прогнозную модель для поддержки принятия бизнес-решений в топливной отрасли.
Используемые технологии

Используемые инструменты:

**Python** - Основной язык анализа

**Pandas** - Загрузка, очистка, трансформация данных

**NumPy** - Математические вычисления

**Matplotlib** - Визуализация данных

**Scikit-learn** - Построение прогнозной модели (RandomForest)

**SciPy** - Статистические тесты (корреляция Пирсона)

## 📁 Структура проекта

Dataset petrol.csv # Исходные данные (цены на бензин)
Анализ статистических данных о ценах на бензин в  ЮФО.ipynb # Jupyter Notebook с полным анализом
